# Attribution and contribution boundary

ContentGenie is derived from [ShortGPT](https://github.com/RayVentura/ShortGPT), an experimental content-automation framework created by Ray Ventura. The repository retains the upstream MIT license and its copyright notice.

## Upstream foundation

The inherited foundation includes the Python content-engine structure, video/audio editing utilities, asset sourcing, prompt templates, documentation scaffolding, and local generation workflow associated with ShortGPT. Consult the upstream repository for its complete history and contributor list.

## Downstream engineering represented here

The current ContentGenie repository adds or substantially reshapes the product around:

- a Next.js creator studio and private FastAPI integration;
- schema-constrained Gemini story packages and grounded research safeguards;
- deterministic story audits and an editorial scoring pass;
- recent-output similarity checks and production manifests;
- licensed-gameplay discovery, media-rights evidence, and attribution output;
- caption, visual, music, sound-effect, and render-quality automation;
- automated tests for the downstream validation and production safeguards.

Because the published repository was imported as a single squashed commit, this document describes the visible product boundary and does not pretend to reconstruct file-by-file authorship. Future work should preserve normal issue, branch, pull-request, and release history.

ContentGenie is not affiliated with or endorsed by Ray Ventura or the ShortGPT project.
